# 类幸存者

网页端 2D 俯视像素「类吸血鬼幸存者」肉鸽。选一个角色在大地图上生存、清怪、捡经验、三选一升级、点亮羁绊。

在线试玩：[https://tmddwyaaa-source.github.io/rogerlike/](https://tmddwyaaa-source.github.io/rogerlike/)（电脑浏览器，WASD + 鼠标蓄力）  
项目经历（可贴简历）：[项目经历.md](项目经历.md) · 更新日志：[更新日志.md](更新日志.md)

## 游戏设定

- **世界**：固定大地图（11000×11000），浅绿草地，镜头跟随角色。
- **角色（三选一）**：**游侠**（远程蓄力穿透箭）、**战士**（4 血近战、无限穿透、蓄力加长挥砍范围）、**法师**（2 血法球、蓄力放大范围、每点穿透 +20% 伤害）。
- **难度**：难度一活够 10 分钟；难度二还需击败 Boss **2 次**。
- **单位**：蘑菇怪、蜗牛怪（带甲）、裂怪、史莱姆、蝎子怪（远程毒弹）、灰树与普通树；Boss **冰人**（四角弹幕 + 冲刺 + 召唤兰花，死后掉 300 结晶、3 分钟后更强重生）。
- **跟班**：地精、兔子、蝙蝠、奇怪的蛋（三段成长），独立索敌、各自索敌。

## 游戏目标

- **难度一胜利**：存活 **600 秒（10 分钟）**。
- **难度二胜利**：击败 Boss **2 次**且活满 600 秒。
- **失败**：生命归零。
- 过程：击杀与毁树掉经验结晶 → 升级三选一 → 集齐羁绊档位越打越强，刷怪同时变密变硬。

## 操作与蓄力

WASD 移动，鼠标瞄准，**按住蓄力、松开发射**（满蓄约 **0.75 秒**），攻击间隔 **0.315 秒**。三角色蓄力收益不同：游侠满蓄伤害 ×2 并穿透；战士蓄力线性加长挥砍范围与伤害；法师蓄力放大法球与范围伤害。

升级「技巧」减蓄力时间（减到 0 即点射满蓄）；「唯快不破」按次加快攻击频率；「暴击」+「精益求精」组成暴击流；「散射 / 开眼了 / 大娃 / 强化射击」等改变弹道形态。

## 羁绊

选过同类**不同种类**的升级即累计档位，右侧显示 chip，悬停可看全部档位与当前进度：

| 羁绊 | 计入升级 | 档位效果 |
|------|----------|----------|
| **天行健** | 敏捷、力量、生存、穿透、技巧等 11 种 | 按档位**随角色等级**补发移速 / 伤害 / 空血上限 / 穿透 |
| **万物一心** | 地精、兔子、蝙蝠、蛋 | 按档位给全体跟班加伤、分享角色伤害 20%、攻击单位 +1、提速并**优先攻击角色正在攻击的目标** |
| **小金刚** | 大娃、黑洞 | 敬请期待 |

## 音效与设置

- 9 种音效：射击（按角色区分弓 / 挥砍 / 法球）、拾取结晶、受伤、升级、低血量心跳、失败、通关。
- **总音量 / 背景音乐 / 音效音量**三滑条独立调节，实时生效。
- 测试模式：无敌、满蓄、火柴人木桩、刷怪速度、时间滑条、升级选项自选面板。

## 本地运行

```bash
cd frontend
npm install
npm run dev
```

打开 [http://localhost:5173/](http://localhost:5173/)。不启动后端也能玩。「回忆」存在当前浏览器，打完一局才有记录。

## 技术栈

| 部分 | 技术 |
|------|------|
| 游戏 | Vue 3、Vite、Canvas 2D |
| 统计 API（可选） | Spring Boot 3、Java 17、MyBatis-Plus、MySQL |

统计默认连 `http://localhost:8080/api`。后端没开时开局会忽略上报，不影响游玩。本机 MySQL 密码写在 `application-local.yml`（不进 Git）。
