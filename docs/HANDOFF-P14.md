## 2. 武器 / 弹体 / 击退（M5）

按 `player.charId` 分支。挥砍不要 chromaBlack。

### 2.1 游侠强化射击 → 激光

停用 `强化箭矢-1/2/3.png`。改用 **一张** `子弹/强化箭矢x.png`（576×96 = 6 帧 × 96，按立绘切帧播放）。

- 画面是**一道激光**，沿飞行方向拉长绘制（`drawW` 明显大于 `drawH`），不要把整张 576 当静态弹体贴出去。
- 仍是飞行判定。速度比普通箭 **520 快一截**：`EMPOWER_SPEED = 680`（约 ×1.3）。
- 数值不变：满蓄 `ceil(攻击×2.5)`，穿透 +2，过量可溢出；第二次 +15。

### 2.2 法师大小

`MAGE_FULL_SIZE`：**2.3 → 2.6**。未蓄仍接近箭矢再略小；中间按蓄力线性。现在 9×2.3 几乎看不出变大——把未蓄边长收到 **7～8**，满蓄 ×2.6 要一眼能看出变大。碰到消散 / 满蓄范围伤规则不变。

### 2.3 战士

| 项 | 规格 |
|----|------|
| 攻击 | 仍 **22** |
| 穿透次数 | **无限**（范围内碰到的都能打到，不消耗穿透、不因穿透停） |
| 基础击退 | **0** |
| 穿透升级 | 每 1 点穿透 → **+0.5 身位**击退（`pierceBonus * 0.5 * BODY`）。未蓄/满蓄都这样，满蓄不再另加击退 |
| 未蓄范围 | 仍 **1.5 身位**；贴图大小 = 碰撞体积 = 这个范围 |
| 满蓄 | **范围和贴图都 ×1.6**（倍率，相对未蓄）。游侠满蓄仍 ×1.25，不要改游侠 |
| 位置 | 身前一截，方向跟鼠标；只结算一次 |

当前 `SLASH_DRAW=30` 偏小：未蓄绘制/碰撞边长按 **1.5 身位（BODY*1.5）** 对齐，满蓄再 ×1.6。`SLASH_RANGE`（身前偏移）随同一倍率走。

`pierceForChar('warrior')` 对消耗型穿透可返回很大值或单独 `infinitePierce`；击退不要再走 `knockbackForCharge` 的 1→2 身位。

### 2.4 击退缩放

`applyKnockback`：最终位移 `max(0, dist − resist) * (target.knockbackScale ?? 1)`。冰人会设 `knockbackScale: 0.5`。

自测：

- `EMPOWER_SRC` 只有强化箭矢x；速度 680
- 法师满蓄 sizeMul 含 2.6；未蓄绘制 < 9
- 战士无限穿透：同一次挥砍可打盒内全部目标
- 战士 pierceBonus=2 → 击退 `BODY`；pierceBonus=0 → 击退 0
- 战士满蓄 sizeMul 含 1.6（未蓄 1）
- `knockbackScale: 0.5` 时位移减半
- `node src/game/combat/selftest.mjs` 全绿

## 3. 冰人与兰花（M6）

`chase()` 默认追玩家：**冰人 / 兰花不要走这套**。接触：冰人掉 1 血；兰花 **不**掉血。

### 3.1 冰人 `ice_man`

| 项 | 值 |
|----|-----|
| 贴图 | `小怪/冰人.png`（32×32 单帧，深色底透明） |
| 出场 | 存活 **≥420 秒** 刷 **1** 只；死后不补 |
| 生命 | **1000**，无成长 |
| 击退 | 可击退，`knockbackScale = 0.5`（只吃 50%） |
| 平时移速 | **生成时** `player.speedUnits * 0.7`（快照，之后不随角色升级变） |
| 接触 | **−1 心**（乱晃碰到也算） |
| 掉落 | 无（或 0 结晶） |

**平时**：在地图乱晃（随机方向，偶尔转向）。尽量留在角色视野（相机 400×225）内；若在视野外，先向视野矩形靠近，进了再继续晃。**不要**为了贴脸而追角色。

**逃跑**：`takeHit` 累计伤害。满 **400** → 进入逃跑 10 秒：移速 = **角色当前 `speedUnits + 0.2`**（×80 成 px/s），方向远离角色，但仍夹在视野边缘晃，禁止跑出视野。10 秒结束清零累计，重新开始 400 计数。逃跑期间不累计这 400。

**弹幕（每 30 秒一套）**：从**视野黑边**（相机矩形边）朝角色飞。素材 `子弹/怪物子弹.png`（4×4）。每发 **−1 心**。一套 = 下面 4 种**随机打乱**各做一次（种与种之间短间隔，建议 0.5～0.8s）：

1. 四角同时 4 发  
2. 十字（上/下/左/右边中点）同时 4 发  
3. 四角依次 4 发（非同时）  
4. 十字依次 4 发  

生成世界坐标：`camera` 四角 / 四边中点。方向指向**当时**角色位置。

**冲刺（每 20 秒）**：随机 **1～3** 次。每次 **0.25s 预警**后，朝**起冲瞬间**的角色坐标直线冲，**不跟踪**。冲刺速度 = **角色当前移速 × 3.2**（用 `player.speed` px/s）。撞到 −1 心。冷却从该套冲刺打完再算，或从周期起点算（选一种写进常量并自测）。

计时从冰人**生成时**起：约 +20s 冲刺、+30s 弹幕、+40s 兰花。测试把时间拨过 420s 应当帧或下一波检查刷出 1 只。

### 3.2 兰花 `orchid`

由冰人每 **40 秒**在附近（视野内或冰人身旁）生成 1 只。冰人死后不再刷新的；场上已有兰花保留。

| 项 | 值 |
|----|-----|
| 贴图 | `小怪/兰花.png`（32×32） |
| 生命 | **1**，锁死，无成长 |
| 伤害 | **0**（接触不扣玩家血） |
| 移速 | **1.3** 设计单位，无成长 |
| 索敌 | 走向当前**血量较少**的活怪（不含自己、不含冰人也可打其他小怪；优先 `hp/maxHp` 最低或绝对 hp 最低，选绝对 hp 并写进自测） |
| 回血 | 每 **15 秒**：周围 **3 身位**内其他怪物 **+20** 生命（不超过各自 `maxHp`）；兰花自己不回 |
| 数字 | 实际回了血才 `hooks.onHeal(ent, 实际值)`；没有钩子则跳过 |

自测建议：

- 419s 无冰人；420s 有 1 只；hp=1000；`knockbackScale===0.5`
- 兰花 hp 恒 1；`contactDamage` 为 0 或 contactPlayer 跳过
- 移速常量 1.3；治疗半径 `BODY*3`、治疗量 20
- `node src/game/enemies/selftest.mjs` 全绿

弹幕/冲刺可用纯函数测生成点（四角/十字相对 camera）与模式集合大小为 4。

## 4. 设置与选角（M8）

### 4.1 满蓄模式

设置测试项文案 **「无限弹药」改为「满蓄模式」**。字段仍可用 `infiniteAmmo`（避免大改持久化）。效果不变：蓄力上限视为 0。

### 4.2 测试时间滑条

仅测试模式显示。左右 `<input type="range">`，**0～10 分钟**（0～600 秒）。显示当前分:秒。

- `settings.testElapsedSec`（0～600，建议步进 1 或 5 秒）
- 局内滑动应改 `session.elapsedSec`（导出 `setElapsedSec`）。拨到 600 会触发通关，这是预期。
- 主页改这个数不要改一局已经结束的结算；**开局**若测试模式开启，M1 会用该值当初始时间。

### 4.3 选角悬停

鼠标指向角色按钮时，在立绘旁/下方显示基础属性（可 hover 浮层）：

格式：`血量：N血  伤害：N  穿透：N  特点：…`

| 角色 | 血量 | 伤害 | 穿透 | 特点 |
|------|------|------|------|------|
| 游侠 | 3血 | 20 | 0 | 远程箭矢，满蓄可穿透 |
| 战士 | 4血 | 22 | 0 | 近战，无限穿透，每有一点穿透获得0.5的击退效果 |
| 法师 | 2血 | 25 | 0 | 法球碰到消散，满蓄范围伤害 |

数据放 `CHARACTERS` 或并列常量，不要写死在三个按钮里各抄一份数字。穿透升级文案可补一句战士转为击退（可选，不阻断）。

自测：设置默认文案含「满蓄模式」或 Settings 模板字符串；`testElapsedSec` 默认 0、clamp 到 0～600；三角色 stats 字段齐全。`node src/ui/selftest.mjs` 全绿。不要改 backend。
