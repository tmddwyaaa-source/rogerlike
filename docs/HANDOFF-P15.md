## 2. 武器 / 暴击 / 法师扩散 / 战士判定（M5）

按 `player.charId` 分支。挥砍不要 chromaBlack。

### 2.1 暴击

| 项 | 值 |
|----|-----|
| 默认暴击率 | **0**（百分数，0%） |
| 默认暴击伤害 | **×1.5** |
| 升级 `crit` | 暴击率 **+10**（可叠） |

- `weapon.critRate` 初值 0；`applyUpgrade('crit')` → `critRate += 10`。
- 每次**出手**（一发箭/一发法球/一次挥砍）掷一次：`random()*100 < critRate` 则该发伤害 ×1.5。同一发法师扩散内所有目标共享这次暴击。
- 跟班不暴击。树木命中也走同一发的伤害（若该发已暴击则树也吃暴击伤）。
- 导出 `CRIT_CHANCE_PER_PICK = 10`、`CRIT_DAMAGE_MUL = 1.5`、`rollCrit(rate, rng)`。

### 2.2 法师

`MAGE_FULL_SIZE`：**2.6 → 3.0**。未蓄边长仍 7～8。

**伤害**（先加百分比再 × 攻击；蓄力线性到满蓄 50%）：

```text
伤害 = 攻击 × (1 + pierceBonus×0.20 + 0.50×chargeRatio)
```

例：攻击 25、穿透 1、满蓄 → 1.70×25 = **42.5**。未蓄 0 穿透 = 25。不要再走全角色通用的满蓄 ×2。

**穿透**：法师弹体碰到第一个敌人就停，**不再用穿透人数 4**。`pierce` 升级对法师只加 `pierceBonus`（从而 +20% 伤），不增加弹体穿透段数。`pierceForChar('mage', …)` 弹体穿透返回 **0**。

**扩散**（蓄力比例 **> 0** 的法球；点射 ratio=0 碰到消散、只打第一个、不扩散）：

1. 碰到第一个可受伤敌人（`knockbackable !== false`）后停止飞行，圆心钉在该敌人**当时坐标**（不跟随）。
2. `MAGE_EXPAND_SEC = 0.3`：绘制边长从「刚命中时的可见大小」线性扩到最大。最大边长 = `ORB_DRAW * sizeMul`（满蓄 ×3.0，再叠大娃）。为让变大看得见，起始边长取 `max(命中边长×0.45, 未蓄边长)`，扩到最大。
3. **扩散开始的那一帧**按**最大半径**对范围内所有敌人各打一次（含被碰到的第一个），并跳伤害数字。之后 0.3s 只播放大，不再结算。
4. 扩到最大（0.3s 结束）后素材消失。
5. 先碰到树/世界：不扩散，直接消失。

### 2.3 战士

身前贴脸打不到的原因：判定中心在 `玩家 + 1.5身位`，近端离身体还有空隙。

- 攻击距离从**身体最前**沿鼠标方向量。半宽按角色宽 11 → 沿瞄准方向 **5.5** 为身体前缘。
- 未蓄覆盖长度 **1.5 身位**（`SLASH_RANGE`）；满蓄长度与贴图 **×1.6**。
- 判定覆盖这段（胶囊或沿瞄准方向的矩形），近端贴身体前缘，远端 = 前缘 + 长度。无限穿透、每目标只结算一次，不变。
- 贴图中心落在这段中点；贴图边长 ≈ 这段长度，**可以略大一点点，但不得超过远端**（不要画出判定外）。
- **满蓄伤害 ×1.6**（替代通用 ×2）：`攻击 × (1 + 0.6×chargeRatio)`，满蓄 22×1.6=35.2。击退仍只跟穿透，基础 0。

### 2.4 游侠

满蓄仍 ×2；强化射击数值不变。只接暴击。

自测至少覆盖：`MAGE_FULL_SIZE===3`；法师 0 穿透未蓄 25、满蓄 37.5；1 穿透满蓄 42.5；满蓄扩散打范围内全部且不超过 1 次/目标；点射不扩散；战士贴脸（身体前 1px）能打到；满蓄伤 ×1.6；`crit` +10 且 100% 时伤害 ×1.5。`node src/game/combat/selftest.mjs` 全绿。

## 3. 冰人 + 测试木桩（M6）

### 3.1 冰人

| 项 | 新值 |
|----|------|
| `ICE_MAN_HP` | **2000** |
| `ICE_DASH_DIST` | **8 × BODY** |
| `ICE_DASH_MIN` / `MAX` | **1 / 6** |
| `ICE_BULLET_SPEED` | **224**（原 160 ×1.4） |

冲刺仍 每 20s、0.25s 预警、锁定点直线、速度 = 角色当前移速 ×3.2、撞到 −1 心。

改口：不要用固定 0.4s 结束。预警结束时记下方向，沿该方向移动，**累计位移达到 8 身位** 才结束这一下；若未到锁定点也继续沿该方向跑完 8 身位。这一下结束后（距离到了）再开始下一次预警。一套随机 1～6 次。

其余（420s、击退×0.5、逃跑 400/10s、弹幕 30s、兰花 40s）不变。

### 3.2 测试火柴人木桩

不是野外怪。测试开关打开时由 M1 调你导出的接口生成。

| 项 | 值 |
|----|-----|
| 素材 | 程序火柴人 `drawStickman`（`render/stickman.js`，只读 import，不要改该文件） |
| 生命 | **999**；每秒回复 **500**（不超过 999） |
| 位置 | 生成时 `player.x + 3*BODY`，`y = player.y`（角色右侧 3 身位） |
| 移动 | 平时完全不动；**不击退**；被打中才闪一下（短 invuln/换一帧 walk 即可） |
| 接触 | **0** 伤害 |
| 掉落 | 无；不计入冰人/兰花逻辑也没关系（血高不会被兰花当最低血） |

导出例如：`DUMMY_HP=999`、`DUMMY_REGEN_PER_SEC=500`、`DUMMY_OFFSET=3*BODY`、`spawnDummyAt(x,y)` / `setDummyEnabled(on, player)` / `removeDummy()`。场上最多 1 个。关掉开关要能移除。可被子弹/跟班打到（进 `targets`）。

自测：冰人 hp 2000、子弹 224、dash 1～6、8 身位结束而非 0.4s；dummy 999/500、右侧 3 身位、接触不伤。`node src/game/enemies/selftest.mjs` 全绿。
