## 2. 毒刺怪 / 冰人 / 怪物体验（M6）

### 2.1 毒刺怪（300 秒肉盾，接替蘑菇怪刷怪位）

| 项 | 值 |
|----|-----|
| 出场 | 300 秒起**蘑菇怪停刷**（场上存量保留至死亡），刷怪位由毒刺怪接管；每 **5 秒**一波 `1 + floor(秒/180)` 只 |
| 血量 | `260 + 20×floor((秒−300)/45)`；难度二每阶再 **+5**（走 `getHpGrowthAdd` 既有接口） |
| 移速 | `0.70 + 0.02×floor((秒−300)/45)` 设计单位，**无帽**（不套 1.4） |
| 击退抗性 | **1 身位**（`knockbackResist = BODY`，同蜗牛：每次击退距离 −1 身位，最低 0） |
| 掉落 | **4 结晶**，每个 **20% 独立概率**为高级结晶（走 M7 接口） |
| 接触 | −1 心 |
| 素材 | `小怪/毒刺怪.png`（已两边就位） |

### 2.2 冰人调整

| 项 | 旧 | 新 |
|----|-----|-----|
| 击退抗性 | 50%（`knockbackScale=0.5`） | **70%（scale 0.3）** |

### 2.3 怪物体验改造

1. **生成预警**：怪物出生前落点显示**红圈约 0.8 秒**再出现。红圈素材原负责人手绘中，未到位先用**程序绘制红色空心圈**占位。
2. **环绕生成**：刷怪位置尽量**环绕角色**（视野边缘外 1～3 身位环带，可调）。
3. **蝎子独立 CD**：每只蝎子**首次开火随机 0～5 秒错峰**，之后各自 **5 秒**节奏（射击间隔 10s→**5s**），消灭齐射。
4. 其余规则维持（怪物移速纯时间制、玩家升级不影响怪物、冰人 420s 出场等）。

## 4. 小金刚羁绊（新增）

- 名称：**小金刚**；计入 = 上述 **七兄弟全部**；**档位只有一个：7**（集齐全部七种）。
- 集齐奖励 = **七色脉冲** + **所有葫芦娃效果的 10% 追加**（一次性）。
  - **七色脉冲**：每 **3.0 秒**自动触发，以角色为中心 **1.5 身位**圈；伤害 **攻击 × 1.3**（每次脉冲单独掷暴击）；减速 **30%、0.4 秒**；**不**施加击退、**不**触发四娃点燃、**不**打破六娃失锁。
  - **10% 追加**：见 §0（大娃 +50%/层、二娃 30%、四娃 20%/s、五娃 30%、三娃 +1 层甲、六娃 +0.25s、七娃再触发一次）。
- chip 平时显示进度（如「小金刚 3/7」），集齐后变身形态显示。
