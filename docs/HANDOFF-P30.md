## 0. 本环已定案

- **恶魔 AI**：改为**独立 AI 单元**，在角色 **3 身位**内**软性自然跟随**（朝角色方向移动，靠近舒适距离即减速停下/自然环绕），**去掉“超 3 身位才冲向角色、贴边界反复扑腾”的空气墙抽搐**。仍保持“攻击离角色最近的怪、常驻角色附近、基础伤害 10+角色伤×20%”。
- **六娃脉冲范围**：`UNLOCK_RADIUS_UNITS` **1.5 → 3**（`UNLOCK_RADIUS=3*BODY`），失锁扩散圈随动。
- **地图背景装饰物**：游戏开始在地图随机生成 **火柴堆 ~25**（素材 1-4）与 **石头 ~75**（素材 5-8，=火柴堆×3）；**静态背景、不可交互、不碰撞**，生成位置**不与其他物体重叠**；绘制在**背景层**（草地之上、实体树/怪之下）。素材已由 M1 拷入 `frontend/public/assets/装饰物/` 与 `assets/source/装饰物/`。

## 1. M11 — 恶魔软性跟随

- `companions`：恶魔移动用“朝角色 + 到达舒适距离减速/环绕”的软跟随，替代当前的 `dist>DEMON_KEEP_RADIUS → moveToward(player)` 硬触发。
- 攻击优先级仍为离角色最近；无敌人时自然绕角色；不要硬性弹回/抽搐。
- 更新 companions/selftest.mjs（软跟随、不抽搐、攻击优先）。

## 2. M4 — 六娃范围 3 身位

- `player/index.js`：`UNLOCK_RADIUS_UNITS = 3`；`UNLOCK_RADIUS` 随之变为 `3 * BODY`。六娃失锁扩散圈视作范围同步。
- 更新 player selftest（范围内外判定用新半径）。

## 3. M7 — 地图背景装饰物

- `world`：新增**背景装饰物**模块（火柴堆/石头），`ensureSeed` 时在地图随机播种：火柴堆 **25**、石头 **75**（=×3），位置**不与已有树/装饰物重叠**（可多次采样空位）。
- 静态背景：`loadAssets` 载入 `装饰物/*.png`，`env.draw` 在草地之后、实体之前绘制；**不参与碰撞、不可交互**。
- 更新 world selftest（数量、不重叠、静态）。
