## 1. 生命与伤害数字（M4）

游侠仍 **3** 心。`createPlayer({ charId })`：

| charId | hp / hpMax |
|--------|------------|
| `ranger` | **3** |
| `warrior` | **4** |
| `mage` | **2** |

`HP_MAX` 可保留为游侠默认；按 charId 设初值。自测：`createPlayer({ charId: 'mage' }).hp === 2`，战士 4，游侠 3。

**伤害数字**（`render/dmgnum.js` 或同等）：

- 同一串数字的格子间距再收紧一点点（现在每格推进 `DMG_TILE=16`，偏疏）。建议推进 **12～13**，数字本身仍按 tile 绘制。
- 伤害 **≥100**：黄外边像素数字。
- 伤害 **≥200**：红外边像素数字。
- 黄边 / 红边由本窗程序生成：在现有 `tile_0–9` 抠黑底之后，给不透明像素描 **1px** 黄（`#e0b84a` 一类）或红（`#c42b2b` 一类）外边。不要另找素材、不要 GenerateImage。
- 仍按单位分开显示。

自测：间距常量 < 16；100 与 199 走黄边路径，200 走红边路径。`node src/game/player/selftest.mjs` 全绿。

## 2. 武器 / 弹体表现 / 升级数值（M5）

按 `player.charId` 分支。不要 chromaBlack 挥砍 / 强化箭矢（已有 1px 黑描边，抠掉会没边）。

### 2.1 游侠强化射击素材（图集，不是发射整张贴图）

`子弹/强化箭矢-1/2/3.png` 各 **576×96 = 6 帧 × 96**，与角色立绘相同处理：

- 按格切帧（`sx = frame * 96`），按时间顺序播。
- 三张为动画变体（可轮换），每张内部切帧，**不要**把整张 576 宽图或整格当静态弹体贴出去。
- 弹体仍是快速飞行判定（速度 780）；画面是这串特效跟着弹体播。

**强化射击数值（替换 P12）：**

| 次数 | 效果 |
|------|------|
| 第 1 次 | 仅满蓄改强化箭表现。满蓄伤害 = `ceil(攻击 × 2.5)`。该发穿透 **+2**（叠在原满蓄基础穿透与「穿透」升级上）。未满蓄仍普通箭。 |
| 第 2 次及以后 | 攻击 **+15**（可叠，不变） |

**溢出穿透（仅强化满蓄）：** 穿透次数用尽、本应停在当前怪时，若本次伤害 **高于该怪剩余血**，溢出伤害继续打轨迹上下一位；溢出仍高于下一位剩余血则可继续，直到打完或没有溢出。

旧常量 `EMPOWER_FULL_MUL=3`、`EMPOWER_PIERCE=4` 删掉或改成 2.5 / 2。

### 2.2 法师

| 项 | 规格 |
|----|------|
| 攻击初值 | **25** |
| 未蓄穿透 | **0**（碰到就消散，只打碰到的那一个） |
| 满蓄穿透 | **4** |
| 未蓄大小 | 与游侠箭矢接近，再小 **1～2 像素**（建议绘制边长 **9**；箭矢长边 11） |
| 蓄力变大 | 随蓄力比例线性变大，满蓄 **×2.3**（相对未蓄法球，不再用全局满蓄 ×1.25） |
| 碰到 | 弹体立刻消失，不飞穿 |
| 满蓄范围 | 命中点附近范围伤害：除第一个外，按穿透数再打范围内敌人（满蓄穿透 4 → 最多再 4 个）。范围跟当前弹体大小走。 |

法师没有强化射击。大娃仍叠在法球大小上。

### 2.3 战士

| 项 | 规格 |
|----|------|
| 攻击初值 | **22** |
| 未蓄穿透 | **1**（身前一次挥砍最多打 2 个） |
| 满蓄穿透 | **2**（最多打 3 个） |
| 距离 | 初始攻击范围 **1.5 身位**（`BODY*1.5`），方向 = 鼠标 |
| 位置 | 挥砍只在角色**身前**一截，不要占半个画面 |
| 大小 | 贴图绘制 = 碰撞体积；基础大小刚好盖过立绘 + 脚下阴影再多一点点（约 28～32 逻辑像素） |
| 伤害 | **只结算一次**。生成时（或首帧）对盒内目标各打一下，之后几帧只播动画，不再 `hitActors` / 刮树 |

`speed = 0`，不飞出。三张挥砍仍切 6 帧播放。满蓄大小仍可叠全局 ×1.25 与大娃，但基准要先收到「盖过立绘」那档，不能再按 48 或整张 576 去画。

### 2.4 大娃

`giantSizeMul(n) = 1 + 0.4 * n`（相对基础）。0 次 = 1，1 次 = 1.4，2 次 = 1.8。不要再「第一次 ×2、之后 +50%」。

游侠 / 战士满蓄默认仍 ×1.25，再叠大娃。法师满蓄大小走 2.3，再叠大娃。

### 2.5 游侠（未改的保留）

攻击初值仍 **20**。未蓄穿透 0，满蓄基础 +1，再加「穿透」升级。未开强化射击时满蓄伤害仍 ×2。

自测：

- 法师未蓄半径明显小于现在的 16；满蓄 sizeMul 含 2.3
- 战士弹体位移 0；首帧后同一目标不再二次扣血
- `empower_shot` 第一次满蓄：攻击 20 → `ceil(50)`，穿透比普通满蓄多 2；过量可溢出到下一位
- 第二次 attack +15
- `giantSizeMul(1)===1.4`，`(2)===1.8`
- `node src/game/combat/selftest.mjs` 全绿
