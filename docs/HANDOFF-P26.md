## 3. M6 — 毒刺怪数量 / 五娃减速 / 四娃五娃粒子 / 红圈占位

### 3.1 毒刺怪基础生成 6

- 每波数量 `1 + floor(秒/180)` → **`6 + floor(秒/180)`**（每 5 秒一波，成长保留）。

### 3.2 五娃减速（敌人真正变慢）

- 敌人移动速度乘 `ent.slowFactor ?? 1`（`slowLeft > 0` 时才生效；为 null/0 则正常）。
- 注意：`slowFactor` 由 combat 写入并扣减 `slowLeft`，本环只补**消费端**，不要改 combat 写入逻辑。

### 3.3 四娃 / 五娃 粒子表现

- 四娃燃烧（`ent.burnLeft > 0`）：怪物身上持续飘**红色**粒子向上；
- 五娃减速（`ent.slowLeft > 0`）：飘**蓝色**粒子向上；
- 粒子**越往上颜色越浅**；**效果结束或怪物死亡**时粒子消失。
- 属怪物侧渲染；不要改 combat 写入逻辑。

### 3.4 红圈预警

- **保留** 程序红色空心圈占位（a 方案）。不要删，等 M10 图标替换。
