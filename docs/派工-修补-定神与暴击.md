> **M3 一个窗两份活**：先做本修补的 `TASK-043`，**完了再**去做批次 6 的验收 `TASK-041`（顺序执行，不要并行）。

## 背景（用户实机反馈 + M1 定位）

1. **定神几乎没效果**：`frontend/src/game/player/index.js` 的 `stepSteady()` 把 **正在蓄力** 与 **刚攻击完** 也当成打断条件；
   而本作开火必须「按住鼠标蓄力再松手」→ 按下左键那一刻就绪就被清空 → **实机永远吃不到那 +100**。
   用户定稿：**静止 = 不按 WASD**；**蓄力、攻击、受击都不打断**；移动才会重新计时。
2. **暴击伤害倍率**：上一版对「暴击率 / 3」取了档（`ceil`）——用户澄清 **「向上取整」指的是伤害数字**，
   倍率要**连续**算；并且飘字「×倍率」标签要**固定两位小数**，让精益求精的收益看得出来。

## 口径一览（以各任务 manifest 的 R 项为准）

| 项 | 最终口径 |
|---|---|
| 暴击倍率 | `1.5 + 0.02 × (暴击率 / 3) × 精益求精层数`（**连续、不取档**；0 层恒 1.5；暴击率不封顶） |
| 伤害数字 | 最终伤害在打出去之前 **`Math.ceil`**（飘字与扣血一致；整数幂等） |
| 飘字标签 | 「×倍率」固定**两位小数**：`×1.50` / `×1.57` / `×2.17` / `×3.50` |
| 定神静止 | **只有 WASD 位移会打断**；蓄力 / 攻击 / 受击都不打断；死亡仍清零；阈值仍 **0.15s** |
| 定神效果 | 那一发 **暴击率 +100**（真实值 → 必暴，且进上面的连续倍率算精益求精） |
