## 1. 选角屏（StartView / RangerPortrait）

1. 立绘在卡框内**整体下移**（现偏高，下部空）；下移量以验收为准：**立绘 + 脚下阴影的组合与对局中「人站在阴影上」的观感一致**。
2. 立绘**脚下加阴影**：复用 `Other/Shadow.png`，缩放对齐立绘宽（三张角色卡一致）；悬停待机动画（P29 已有）播放时阴影保持在脚下不跟着跳。

## 2. 回忆详情页布局重排（MoreView）

现状：羁绊、升级选项为左右各约 50% 的两个独立大框。改为：

- **升级选项**：保留现有面板框，宽度占 **≥60%**；内容（图标+×n、悬停看效果）不变。
- **羁绊**：**删除独立大框**，改为与局内 `rl-bonds` 同款的**裸 chip 竖排**（一个小 chip 一条羁绊），放在右侧剩余约 40% 区域，顶部与升级选项面板对齐。
- 左右两部分**合计宽度 = 上方等级黑框宽度**，底边对齐（高度不一时以内容自然高度为准，不强拉伸）。
- 羁绊 chip **悬停提示完整保留**：说明行 + 全部档位列表 + 已达/未达深浅色（沿用 P20/P24 的 `rl-bond`/`rl-bond-tip` 机制即可，可直接复用类名）。

## 3. 回忆详情页：立绘阴影贴身

等级黑框内的角色立绘：阴影从现在的「远距离悬空」改为**贴在立绘正下方脚下**，人物底到阴影的垂直间距 = **对局中角色脚下阴影的间距**（同一素材同一比例）。

## 4. selftest 同步

- 既有断言全保留（`rl-mem-tip`、`4ch`、`×{{ u.count }}`、`rl-char-tip`、`pre-line`、`.rl-bonds`+`flex-wrap`+`282px` 等按现状核对，若布局改动波及则同步改断言并在交付说明里列出）。
- 新增建议：`StartView` 含 Shadow 引用；`MoreView` 羁绊区不含独立大框类名（或含新布局类名，实现自选后固定断言）。

`node src/ui/selftest.mjs` 全绿。
