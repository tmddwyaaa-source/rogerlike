## 2. 蝎子 / 冰人 / 史莱姆 / 灰树 / 难度血（M6）

### 2.1 蝎子怪 `scorpion`

贴图 `/assets/小怪/蝎子怪.png`（32×32 单帧，绘制同蘑菇）。  
解锁 **300s**，成长 `u = max(0, 秒−300)`。

| 项 | 值 |
|----|-----|
| 生命 | `100 + 10×floor(u/45)`（难度二再走 §2.5） |
| 接触 | −1 心；可击退；减免 0 |
| 刷怪 | 每 **20** 秒一波；每波 `2 + floor(u/30)` |
| 移速 | `0.8 + 0.05×floor(u/45)`，无 1.4 帽 |
| 掉落 | **2** 结晶 |

行为（身位 `BODY=22`）：

- 距玩家 **>8 身位**：靠近。
- **3～8 身位**：站住，每 **10s** 朝玩家打一发（`怪物子弹.png`，速度 **180**，−1 心）。可并入现有冰人子弹列表，速度单独写。
- **<3 身位**：背离跑到 **7 身位** 再停。

远了要追，不要在视野外发呆。接触仍伤人。

### 2.2 史莱姆 x-1

- `SLIME_X1_HP0` **85→115**
- `SLIME_X1_UNLOCK_SEC` **240→180**（第 4 分钟）；数量/移速/血成长都从 180s 起算。
- x-3 仍 `ceil(母体生成血×0.25)`，会跟着变厚。

### 2.3 冰人

| 项 | 旧 | 新 |
|----|----|----|
| 冲刺 CD | 20 | **15** |
| 弹幕 CD | 30 | **25** |
| 兰花 CD | 40 | **35** |
| 掉落 | 0 | **300** 结晶（死亡点附近小幅抖动，不要 300 个叠成一点） |
| 重生 | 死后不补 | 死后 **180s** 再刷 1 只；血 = `round(2000 × 1.4^n)`，n=已死亡次数 |

第一只仍 **420s / 2000**。全图同时最多 1 只。逃跑 10s、预警 0.25s、移速倍率 **不改**。

`onKill` 仍要在冰人死亡时调用（M1 用来记 Boss 击杀）。兰花仍不掉结晶。

### 2.4 灰树

- `GRAY_HP0` **25→80**；仍 `80 × (1 + 0.15t)`，`t=floor(秒/45)`。
- 自损仍每 **3s** 一次，下限 **1**。
- 上限 = **`8 + floor(存活秒/60)`**（0 分 1～8，1 分 1～9）。`rollGraySelfDamage(random, elapsedSec)`。

### 2.5 难度二血成长 +5

不要写死「永远 +5」。提供 `opts.getHpGrowthAdd?.() ?? 0`（M1 接线：难度二返回 5）。

加在「每阶 +N 血」上：

- 蘑菇 / 裂怪：`5 + extra`
- 蜗牛：`10 + extra`
- 史莱姆 x-1：`12 + extra`
- 灰树百分比、冰人、兰花：**不加**

自测：蝎子 300s 才刷；血/波次/移速公式；冰人 CD 15/25/35；死后 180s 重生血 2800；灰树 t=0 血 80；自损上限 8 起；`getHpGrowthAdd:()=>5` 时蘑菇 t=1 为 27+10。`node src/game/enemies/selftest.mjs` 全绿。不要改 combat / match.js。

## 4. 羁绊 / 难度二 / 通关（M8）

### 4.1 去掉升级白送

升级时 **不要再** 调 `applyLevelGrowth` / `applyEmptyHpMax` / `applyPierceGrowth`。  
力量 / 敏捷 / 生存 / 穿透 **选项本身仍有效**。

天行健按 **当前角色等级** 补发（档位变化或升级都要重算差额，避免漏加或连加）：

| 已达档位 | 效果 |
|----------|------|
| 2 | `floor(等级/2) × 0.01` 移速 |
| 4 | `floor(等级/2) × 1` 伤害 |
| 6 | `floor(等级/10) × 1` 空心上限 |
| 8 | `floor(等级/15) × 1` 穿透 |

### 4.2 类型（`bond` 字段）

**天行健** `qian`：敏捷、力量、生存、穿透、技巧、唯快不破、暴击、精益求精、散射、开眼了、强化射击。档位 **2 / 4 / 6 / 8**。

**万物一心** `unity`：地精、兔子、蝙蝠、奇怪的蛋。档位 **3 / 6 / 9**。本环只有 4 种，**只能到档 3**；6 / 9 仍要实现，以后加跟班就能点亮。

**葫芦娃**：不做。大娃无 `bond`。

档位 = 本局选过的该 `bond` **不重复 id** 个数（`Set`）。测试「升级选项自选」同样计入。

万物一心达标后调跟班（有则调，无则 pending）：

- 档 3：`syncUnityBond({ kinds })` 或 `setUnityTier(3|6|9)`
- 档 3：跟班伤 +5（只加一次）
- 档 6：跟班额外 `floor(角色攻击×0.1)`
- 档 9：每只可打目标 +1

### 4.3 右侧显示

`session.bonds`：只含 **已有至少一档** 的羁绊 `{ id, title, rank }`。  
`HudOverlay`（或并列组件）画在画布 **右侧** 深色空白（齿轮下方，`right` 对齐，不要盖画布）。并排，**一行最多 3 个**（flex wrap）。文案例如「天行健 4」。没档的不占位。暂停/升级也显示。

### 4.4 难度二

```
DIFFICULTY_TWO = { id: '2', name: '难度二' }
OBJECTIVE_TEXT     仍「目标：活够10分钟」（难度一）
OBJECTIVE_TEXT_TWO 「目标：击败Boss 2次，并活够10分钟」
```

选难度两颗按钮，悬停各自目标。`session.difficulty` 写入 `'1'` / `'2'`。  
`session.bossKills`（M1 冰人死亡时 `addBossKill()`）。

通关：

- 难度一：存活 ≥600s → 胜（与现在相同）。
- 难度二：存活 ≥600s **且** `bossKills >= 2` 才胜。满 10 分钟但只打了 1 次 → **继续打**，不要强行胜。测试时间拨到 10 分钟同样。

自测：白送成长不再加；选 2 种 qian 才有速；叠力量两次仍 1 种；难度二不满 2 杀不胜；bonds 快照。`node src/ui/selftest.mjs` 全绿。不要改 backend、不要生图。
