## 【M2】荆棘范围 / 精益求精 / 连射延迟 / 定神临时暴击率

- **任务**：`TASK-033`（四条 R，逐条照 manifest 的 `verify_cmd` 跑）
- **四条口径**
  1. **荆棘**：作用半径 `4 身位` → **`2 身位 + 0.5 身位/层`**；**伤害倍率不变**（`1.5 + 0.5×(层−1)`）；0 层零伤害。
  2. **精益求精**：每次选择**再 +5 暴击率**（可叠）；暴击伤害倍率改为 **`1.5 + 0.02 × ceil(暴击率/3) × 层数`**（粒度 3 点、向上取整、按层相乘）；**暴击率无上限**，超过 100 的部分照算。
  3. **连射**：额外那一发**晚 0.2s** 射出（用 `update(dt)` 真实计时，**不要 setTimeout**）；额外冷却仍 **0.75s**、主发间隔不受影响；额外那一发**仍吃既有加成**（口径不变）。
  4. **定神（战斗侧）**：`consumeSteadyCrit()` 从「强制暴击」改为「**该次攻击暴击率 +100**」，这 100 点**同时参与**暴击判定与暴击伤害档位（所以能吃精益求精），**只这次**。
- **不要碰**：玩家侧 `player/**`（阈值归 M3）、`ui/**`（文案与卡牌屏归 M6）。

- **四条口径**

  2. **生生不息文案**：`BOND_DESC[BOND_SHENG]` 现在把计入项（生存/恢复/三娃/滋补/荆棘）写给玩家了 → 改成与天行健同款 **`不同种类升级集齐解锁档位`**；档位效果两行保留；任何悬停/tip 都不得再暴露计入项。
