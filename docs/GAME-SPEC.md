## 2. 主角

三种角色逻辑尺寸相同：宽 **11**、高 **22**（身位 `BODY=22`）；WASD + 鼠标瞄准；**按住蓄力、松开攻击**；受伤 −1；无敌约 **0.85s**；移速 **1.20** 单位 × 80 = **96** px/s。  
生命初值：**游侠 3 / 战士 4 / 法师 2**。  
升级不再白送攻/速/空心/穿透；改由羁绊天行健按档位与 `floor(等级/N)` 发放。  
脚下 `Other/Shadow.png`。无 Image 时火柴人兜底。死亡：`characters/{1,2,3}/*_Death.png` 均为 **8** 帧溶解，播完再结算。

游侠满蓄弹体与碰撞默认 **×1.25**，再叠「大娃」。战士未蓄挥砍从**身体前**沿鼠标 **1 身位**长条（厚约 0.5 身位），蓄力线性到范围/伤害 **×1.6**；大娃加长度与厚度，不要把长度当正方形边。法师弹体随蓄力线性变大，满蓄 **×3.0**（相对未蓄法球），再叠大娃。命中显示本次**实际扣血**（有甲为 ×0.7 后；灰树/浅树也弹；`游戏数字/tile_0–9.png`）；位数间距略收紧；**≥100 黄边、≥200 红边**；回血为**绿边**（程序描边）。选难度：难度一「目标：活够10分钟」；难度二「目标：击败Boss 2次，并活够10分钟」。选角悬停为「基础属性」+「角色特点」。默认暴击率 **0**；触发按 min(率,100%)；暴击伤害 **×（1.5 + 0.2×floor(率/30)×精益求精层数）**。攻击间隔 **0.48s**，唯快不破 ÷1.2。

### 4.1b 激发力量 `power`（每 10 级一次，P42 批次 3）

触发：等级每到达 **10 的倍数** 欠一次；**常规三选一收尾后**再单独进 power 屏，**强制选 1 张**（无跳过/关闭接口，ESC 与设置入口在该相位屏蔽）。跨级时按跨过的 10 倍数个数逐次补齐。power 屏内对局冻结（同升级）。

候选池：游侠 = `rapid` / `pierce_amp` / `steady` / `sp`；战士、法师 = 仅 `sp`。`rapid`、`pierce_amp`、`steady` **各限一次**，`sp` **可叠**。

| ID | 名称 | 效果 |
|----|------|------|
| `rapid` | 连射 | 不蓄力开火 **50%**、满蓄 **100%** 概率额外发射（额外发独立 **0.75s** 冷却，主发间隔不受影响） |
| `pierce_amp` | 贯穿强化 | 穿透 **+1**；每穿过 1 个敌人本次伤害 **+50%** |
| `steady` | 定神 | 静止 **0.3s** 后下一次攻击**必暴**；只吃一次，移动/受击/死亡重置，被攻击间隔挡下时不消耗 |
| `sp` | sp-power | 伤害 **+20**（可叠） |

表现：空白卡从左往右漂移循环、像素字「选一张」无框；点击后其余卡飞离，被选卡居中 `scaleX` **`steps()`** 翻转，停 0.6s 后淡出。回忆：每次记一条**空白图标**条目，名称「激发力量」，悬停「激发力量 · 效果名」。**不计入任何羁绊**（回忆 id 用 `power_` 前缀，区别于常规升级 `power`=力量）。

### 4.2 跟班

独立属性，不是武器。无血、无击退。移速 = 选择该跟班时角色当前 px/s。每只跟班独立锁定不同敌人（优先领尚未被其他跟班占用的活目标；**恶魔例外**：永远取离角色最近的活怪，允许与其他跟班同一目标），走进绘制矩形重叠才造成伤害。兔子从目标朝向角色的一侧切入，不要跟在怪身后同向空追。没敌人则跟角色。暂停/升级时跟班冻结。碰撞：绘制矩形重叠才造成伤害。多只跟班不要叠成一张图。
