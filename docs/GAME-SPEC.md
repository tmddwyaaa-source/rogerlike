# 类幸存者 — 游戏规格（M1 定稿）

> 主导窗口维护。实现以本文件 + `MODULE-REGISTRY.md` 为准；与代码冲突时以代码常量为准并回写本文件。  
> 最后对齐：2026-08-18（P11 已入局：跟班独立索敌、回忆悬停、怪物数值、力量+10、每5级成长）

## 1. 产品定位

| 项 | 内容 |
|----|------|
| 游戏名 | **类幸存者** |
| 类型 | 网页端、类吸血鬼幸存者、肉鸽感 2D 俯视像素 |
| 叙事 | 暂无剧情背景 |
| 视觉 | 浅绿简约；草地/环境色对齐 `浅树.png` 色板 |
| 技术 | 前端 Vue 3 + Vite + Canvas；后端 Spring Boot 3 统计局数据 |
| 可玩角色 | **游侠**（其余「敬请期待」） |
| 可玩武器 | **游侠弓**（无选武器页） |
| 难度 | 仅 **难度一**（`id: "1"`） |
| 通关 | 存活 **600 秒** → 强制胜利 |
| 失败 | 生命归零 → 结算 |

## 2. 主角「游侠」

| 项 | 规格 |
|----|------|
| 形象 | Craftpix `characters/1/`（D/S/U Idle/Walk/Attack/Hurt/Death）；脚下 `Other/Shadow.png`；无 Image 时火柴人兜底 |
| 逻辑尺寸 | 宽 **11**、高 **22**（身位 `BODY=22`） |
| 操作 | WASD 移动 + **鼠标瞄准**；**按住蓄力、松开发射** |
| 生命 | 上限 **3**；受伤 −1；像素飞散 + 无敌约 **0.85s** |
| 移速 | **1.20** 设计单位 × 80 = **96** px/s |
| 等级成长 | 每升 **5** 级（到 6 / 11 / 16…）：攻击 **+1**，移速 **+0.05** 设计单位 |
| 武器 | 游侠弓；无弹匣、无换弹 |
| 蓄力 | 上限 **0.75s**；两次攻击间隔 **0.21s** |
| 伤害 | 独立攻击属性（初值 **20**）；未蓄 = 攻击；满蓄 = 攻击 ×2 |
| 击退 | 未蓄 **1 身位** → 满蓄 **2 身位**；`knockbackable===false` 不位移；可减免，**最低 0** |
| 穿透 | **仅满蓄** 基础可再穿 1 个；升级「穿透」每次再 +1 |
| 箭矢 / 击中 | `Other/Arrow.png`；`Other/{D,S,U}_Blood.png` |

| 项 | 规格 |
|----|------|

## 4. 经验与升级

| 项 | 规格 |
|----|------|
| 蘑菇怪 / 蜗牛怪掉落 | **1** 结晶（= 1 经验） |
| 史莱姆x-1 掉落 | **2** 结晶 |
| 史莱姆x-3 掉落 | **0 或 1** 结晶（各 50%） |
| 普通树掉落 | 结晶 **3～(6+2×floor(秒/60))** + **30%** 红色像素水果（回 1 心）；满 1 分钟起为 3～8 |
| 吸附 | 距主角 ≤ **2 身位** 自动吸入；升级「磁铁」每次当前范围 **×1.5** |
| 吸入速度 | **135** px/s（原 90 的 +50%） |
| 升级阈值 | `expNeed = 15 + 4×(level−1)`；**无等级上限** |
| 升级 UI | 先播完 **+1**，再抽 **3** 项。普通池日常抽；**每第 5/10/15… 次**三选一有 **30%** 将其中 1 格换成高级项 |
| 升级表现 | 每次升 1 级先播 **+1**，播完再出三选一（自然捡结晶与测试提高相同）。升级期间结晶可飞、不拾取 |
| 蓄力打到 0 | **移出**「技巧」选项 |
| 回忆 | 对局升级图标从左到右；图标间距能写下 ×000；次数为 1 也显示 ×1；**鼠标对准图标显示该选项效果** |

### 4.2 跟班

独立属性，不是武器。无血、无击退。移速 = 选择该跟班时角色当前 px/s。每只跟班独立锁定不同敌人（优先领尚未被其他跟班占用的活目标），走进绘制矩形重叠才造成伤害。兔子从目标朝向角色的一侧切入，不要跟在怪身后同向空追。没敌人则跟角色。暂停/升级时跟班冻结。地精/兔子碰撞：绘制矩形重叠才造成伤害。多只跟班不要叠成一张图。

地精贴图：`跟班/地精.png`。兔子贴图：`跟班/兔子.png`。升级图标：`upgrades/goblin.png`、`upgrades/rabbit.png`。高级项左上 3×3 红点。

## 6. 难度一（当前唯一难度）

- 蘑菇怪 / 灰树阶：`t = floor(存活秒/45)`。
- 蘑菇怪移速：`px/s = 80 × min(1.4, 0.75 + 0.08t)`。裂怪同前（base 0.9）。
- 蜗牛怪阶从 120s 起算，见 §5.1b。
- 史莱姆x-1 阶从 300s 起算，见 §5.1c。
- 测试「刷怪速度」：`每波数量 = max(1, round(基础×spawnRate))`（仅测试模式）。

| 对象 | 数量/波 | 间隔（秒） | 移速 | 生命 |
|------|---------|------------|------|------|
| 蘑菇怪 | `5+floor(秒/120)` | **5** | `(0.75+0.08t)×80`，帽 1.4 | `27+5t` |
| 蜗牛怪（≥120s） | `4+floor((秒−120)/45)` | **5** | `(0.75+0.07×u)×80`，u 从 120s 起算，无 1.4 帽 | `45+10×floor((秒−120)/40)` |
| 灰树 | 2（需 ≥30s） | `max(2, 5×0.94^t)` | — | `25×(1+0.15t)` |
| 普通树 | 1 | `max(5, 10×0.97^t)` | — | `50+5t` |
| 灰树裂怪 | 4 / 次毁坏 | 毁坏后 +1s | `(0.9+0.08t)×80`，帽 1.4 | 同蘑菇怪；贴图 `裂怪.png` |
| 史莱姆x-1（≥300s） | `6+floor((秒−300)/45)` | **15** | `(1.00+0.07u)×80`，无帽 | `85+12×floor(u/45)` |
| 史莱姆x-3 | x-1 死 ×3 | — | 母体死时移速 +0.10 | `ceil(母体生成血×0.25)`；出生 0.3s 无敌 |

「靠近 + 视野外」：环形带（视野矩形外、距主角 ≤ 1000）。

## 7. UI

1. 开始：**主页 → 选角 → 难度**（无选武器）；选角页游侠为 **朝右** 的 `S_Idle` 第 0 帧  
2. 局内 HUD：心、**蓄力条**、等级/经验、存活时间、角色名  
3. 画布外右上黑色区域：**齿轮**；齿轮或 **ESC** → 暂停并打开设置；再 ESC 关闭并恢复  
4. 设置「返回主页」确认：「返回后本局无法保持，是否退出？」  
5. 升级：先角色旁 **+1**，播完再出三选一（自然捡结晶与测试提高相同）。升级期间结晶可飞、不拾取。每第 5 次三选一有 30% 出 1 个高级项；高级图标左上 3×3 红点  
6. 结算：存活时间等 → 提交后端  
7. BGM：`/assets/游戏音乐/music.ogg` 循环；音量滑条即时  
8. 回忆对局：升级图标从左到右，间距能写下 ×000；次数为 1 也显示 ×1；高级项同样有红点；**鼠标对准图标显示该选项效果**  

测试模式「无限弹药」：蓄力上限视为 0。  
测试模式「提高等级」：0～3，**关掉设置后**先播 +1，再弹出最多 3 次三选一（仅局内）。  
测试模式「刷怪速度」：与当前时间基础每波数量相乘。
