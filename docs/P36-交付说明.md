## 4. 交互规则落地

- hover **不改填充色**：CSS 扫描仅 `.rl-action-row:hover::before` 有 `background`（即 4×4 像素箭头本体）；`.rl-btn:hover` / `.rl-action-btn:hover` / `.rl-mem-item:hover` 均无 `background`。
- 反馈方式：下压 1px + 硬阴影缩短（active 再下压 1px）+ 左侧像素箭头 + `focus-visible` 3px outline。
- 开关开启态继续用现有 `--rl-panel` 自然色，无荧光亮绿。
- 信息容器（设置分组面板、结果信息区、回忆详情信息区）保持 1px 轻量。
