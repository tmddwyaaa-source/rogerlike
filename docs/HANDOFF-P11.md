## 1. 跟班独立索敌 + 兔子别空追（M11）

**玩家感到的问题：**

1. 兔子贴着怪，突然和怪同方向追角色，撞不上、不打伤。
2. 多跟班像一张大图：动作一致、全朝同一只怪，多只要和一只没差别。

**根因（不要维持）：**

- 地精全部 `nearestTo(player)`，共用一个目标。
- 追击落点是绕目标的 **ring 槽位**（`slotPos` + `ringRadius`），停在怪体外圈，经常 **AABB 不重叠** → 碰撞伤害为 0。
- 兔子从怪背后追当前坐标，怪也在追角色，三者同向，贴着空跑。

**新规则（地精和兔子都要独立索敌）：**

| 项 | 规格 |
|----|------|
| 分配 | 每只跟班尽量领 **不同的** 活目标。贪心：按跟班列表顺序，选离自己最近、且尚未被其他跟班领走的 `getTargets()` 单位 |
| 锁目标 | 当前目标仍活着且仍在 `getTargets()` 里就 **不要每帧换**；死了或消失再重新分配 |
| 怪不够 | 允许共享；共享时从不同接触角靠上去，仍要能重叠 |
| 移动终点 | **走进绘制矩形并重叠**。禁止再把落点放在会避免重叠的大圆环上 |
| 兔子切入 | 终点取目标 **朝向角色的那一侧**（怪与角色之间、仍在怪的 AABB 上），从背后绕到身前切入，不要跟在屁股后面同速跑 |
| 无敌人 | 仍绕角色槽位跟随 |
| 不变 | 无血无击退、移速快照、0.4s、地精最多 2（彼此重叠才 2）、兔子最多 1、伤害公式 |

目标池不变：蘑菇怪 / 蜗牛怪 / 裂怪 / 灰树 / 史莱姆。不要追结晶、玩家、其他跟班。

**自测必须覆盖：**

- 两只跟班、两只相距足够远的怪：各自朝不同的怪移动（不要两只都朝同一只）。
- 兔子在怪背后、怪在角色与兔子之间：`update` 后兔子 x 应靠近怪（能重叠），不要只跟着怪往角色方向平移且保持不重叠。
- 地精旧「全体追离角色最近」断言 **删掉或改成独立分配**。
- `node src/game/companions/selftest.mjs` 全绿。

## 2. 怪物数值（M6）

只改 **怪物**（蘑菇怪、裂怪、蜗牛怪、史莱姆 x-1 / x-3）。灰树、普通树不动。

### 每波 / 爆出数量：基础各 +1

| 对象 | 旧 | 新 |
|------|----|----|
| 蘑菇怪每波初值 | 4 | **5**（公式 `5+floor(秒/120)`） |
| 蜗牛怪每波初值 | 3 | **4** |
| 史莱姆x-1 每波初值 | 5 | **6** |
| 灰树爆裂怪 | 3 | **4**（`GRAY_BURST_COUNT`；错开角度改 90°） |
| 史莱姆x-3 | x-1 死 ×2 | x-1 死 **×3** |

间隔不要改（蘑菇/蜗牛仍 5s，x-1 仍 15s）。

### 基础生命 +5

| 对象 | 旧初值 | 新初值 |
|------|--------|--------|
| 蘑菇怪 / 裂怪（跟蘑菇公式） | 22 | **27** |
| 蜗牛怪 | 40 | **45** |
| 史莱姆x-1 | 80 | **85** |
| 史莱姆x-3 | `ceil(母体生成血×0.25)` | **公式不变**（母体已 +5，不要再额外 +5） |

### 生命成长 +2

| 对象 | 旧 | 新 |
|------|----|----|
| 蘑菇怪 / 裂怪 | +3 / 45s | **+5** / 45s → `27+5t` |
| 蜗牛怪 | +8 / 40s | **+10** / 40s |
| 史莱姆x-1 | +10 / 45s | **+12** / 45s |

### 移速成长 +0.02（初值不变）

| 对象 | 旧成长 | 新成长 |
|------|--------|--------|
| 蘑菇怪 / 裂怪 | +0.06t（帽 1.4） | **+0.08t**（帽 1.4 仍在） |
| 蜗牛怪 | +0.05 / 45s | **+0.07** / 45s |
| 史莱姆x-1 | +0.05 / 45s | **+0.07** / 45s |
| 史莱姆x-3 出生移速 | 母体死时 +0.10 | **不变**（那是出生加成不是成长） |

### 史莱姆x-3 出生无敌 0.3s

现状：`justSpawned` 只跳过 **1 帧接触**，子弹仍能贯穿打死。

新：出生起 **0.3 秒** 内 `takeHit` 不扣血（箭、跟班、任何伤害都不算）；接触也不伤玩家。可移动。0.3s 后恢复。不要用「等下一帧再清」代替计时。

**自测：** 数量/血/成长常量；x-3 生成 3 只；出生 0.3s 内 takeHit 血不变，0.3s 后能死。`node src/game/enemies/selftest.mjs` 全绿。

## 5. 每升级 5 次：伤害 +1、移速 +0.05（M8）

角色成长，不是新升级选项。

- 次数按 **角色等级**：`floor((level−1)/5)`。1 级 0 次；到 **6 / 11 / 16…** 各触发一次。
- 每次：**攻击 +1**（写入方式同力量：`player.attack` 与 `combat` 的 weapon/pistol.attack）、**移速 +0.05** 设计单位（写入方式同敏捷：`speedUnits` + `speed` px/s）。
- `addExp` / `boostLevels` 都要算（一次跳多级按跨过的门槛次数加，不要漏、不要重复）。
- 无 `ctx.player` 时不崩。
- 不要每帧按等级重算叠加速度。

常量建议：`LEVEL_GROWTH_EVERY=5`、`LEVEL_GROWTH_ATK=1`、`LEVEL_GROWTH_SPEED=0.05`。

**自测：** 1→6 攻+1 速+0.05；6→11 再各一次；一次 `boostLevels` 从 4 到 7 只加一次。`node src/ui/selftest.mjs` 全绿。
